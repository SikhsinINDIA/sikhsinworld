# sikhsinworld.com

Static site for GitHub Pages. Every page is generated from `scripts/data.js`.

    node scripts/build.js

- Add a country page: set its kind to `'page'` in `REGIONS` and add an entry in `COUNTRIES`, then rebuild.
- Sister sites: sikhsinindia.com (India and the Sikhi library) and sikhsinuae.com (UAE). Content about the Gurus, Nitnem and Hukamnama is linked to sikhsinindia.com, never copied here.
